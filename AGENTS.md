# Artist Brand Workshop

This repository is an artist interview and build kit. Read WORKSHOP.md before facilitating. Use NAS-KNOWLEDGE.md and the individual notes/transcripts as reference data. SWIM-CASE-STUDY.md demonstrates synthesis; it does not supply answers for a new artist.

Ask one focused question at a time. Keep the session record. Ground interpretations in the artist's answers and specific NAS sources. When the artist confirms the direction, create all six deliverables specified in WORKSHOP.md. Keep private answers out of this template repository unless the artist expressly asks to save them here. Do not publish outputs without authorization.
