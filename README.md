# Artist Brand Workshop

A portable, source-backed workshop for an artist and their AI collaborator. It turns the complete Neighborhood Art Supply research library into focused questions, then turns the artist's answers into a usable brand guide and collaborator kit.

This is a knowledge pack and an interview-to-build workflow. No software setup, API key, subscription to this project, or access to Swim's repo is required.

## Start in Claude, Grok, or another chat assistant

1. Download and unzip this repository.
2. Attach **WORKSHOP.md**, **NAS-KNOWLEDGE.md**, and **SWIM-CASE-STUDY.md** to a fresh conversation or persistent knowledge workspace. WORKSHOP.md includes the interview, templates, and review checklist.
3. Paste this message:

   > Use WORKSHOP.md to run my artist brand workshop. Use the complete NAS-KNOWLEDGE.md as your reference library and SWIM-CASE-STUDY.md as a worked example of synthesis, never as my identity. Start by checking which materials you can actually read, then ask me the first question. Interview me one question at a time. Keep a portable session record. After we confirm the direction, build my complete brand guide and collaborator kit.

If attaching several files is inconvenient, attach **ARTIST-WORKSHOP-ALL-IN-ONE.txt** instead and paste the same message. It contains those three documents in full. Its document boundaries are labeled. It does not contain the raw transcripts; those are included separately in the repository.

If the model cannot read the full upload, have it say what it can see and work through the library in batches. Do not accept a claim that it read the whole source if it only sees a preview. Use the source index in NAS-KNOWLEDGE.md to choose relevant episode notes, and attach matching files from references/episode-notes/ when needed. Exact account upload and retrieval limits vary.

## What you get

- **The whole existing NAS study:** the cross-episode distillation and every one of the 54 episode notes, without selecting only the episodes that support Swim's identity.
- **The original research corpus:** all 54 text transcripts, the catalog, and the source manifest under references/. Audio and video are not bundled.
- **A focused interview:** twelve modules, with anchor questions, conditional probes, source routing, and a clear stop condition.
- **A Swim worked example:** the finished guide plus an annotated explanation of the connections between its central idea, character, sound, audience, beliefs, and visual rules.
- **A build workflow:** synthesize, resolve contradictions, confirm direction, write the guide, make it useful to collaborators, and review against actual answers.
- **A continuation record:** preserve answers, source references, decisions, unresolved issues, and the next question across chats.

The default interview is one question at a time and can span several sittings. It is finished when the evidence is sufficient, rather than when an arbitrary number of questions has been asked.

## Final deliverables the assistant will build

1. brand-guide.md — a finished editorial guide with the same core sections as Swim's.
2. brand-guide.html — a self-contained, responsive, printable guide you can open locally.
3. collaborator-brief.md — a short brief a photographer, designer, producer, or editor can act on.
4. creative-system.md — voice, sound, visual rules, reference directions, and practical examples.
5. first-30-days.md — one feasible recurring format, a small production plan, and a review date.
6. session-record.md — the answers, supporting evidence, decisions, unknowns, and continuation instructions.

A model without file tools can return each file in a separately labeled code block. Save the blocks with those filenames. Generated HTML is a local document: it does not have Swim's server password protection. Ask for a hosted version separately if needed.
